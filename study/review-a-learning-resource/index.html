Check whether a learning resource answers the missed question

An educator’s rubric for matching a follow-up reading or video to a specific learning gap.

MedQ-AI, founded by Christopher Taicher, MD

Define the question the resource needs to answer

Write the learning gap as a question. If a learner confused the timing of an event with its severity, the objective might be to explain which decision changes when the timeline changes. Use that question to review the reading or video.

Score the resource against four checks

  1. Match. Can you point to the passage or timestamp that addresses the specific distinction?
  2. Authority. Can you identify the publisher, date, and evidence the explanation relies on?
  3. Scope. Does it explain the relevant setting and any limits on applying its advice?
  4. Application. Can the learner answer a fresh question after using it?

Record a short reason for each check. A broad topic overview may be useful background. If it never addresses the decisive clue, pair it with a more targeted resource or choose another item.

Keep a short matching note

Record the learning objective, source link, timestamp or section, and one transfer question. If the material is replaced, have the next reviewer check the same objective so the change can be compared consistently.
