Check a question generator before release

A repeatable comparison for medical educators changing a model, prompt, or retrieval source.

From MedQ-AI, founded by Christopher Taicher, MD. Carnegie Mellon lists him on the MedQ AI team.

When a team changes a prompt, model, or retrieval source, reviewers need to know which changes affected question quality. Save a fixed set of fictional or appropriately licensed inputs that represents what the generator will handle, including cases that have already produced failures.

Compare the current and proposed versions

Run the same inputs through both versions. Log the model, prompt, source configuration and run date. For inputs that have produced inconsistent outputs, run each version more than once and keep every output in the review set. Mix and label the drafts so reviewers can judge them before learning which version produced each one.

Score the decision, explanation, and evidence

  • Decision. Is there one defensible best answer given the information in the stem?
  • Explanation. Does it connect the answer to the decisive finding and explain why a plausible alternative is weaker?
  • Evidence. Can the reviewer locate each consequential claim in the cited source, and does the source cover the scenario?

Mark each category pass, revise, or hold. Save the exact passage or reviewer note behind a hold. In a small sample, report the number of checked outputs and the failures by category so a single percentage cannot hide a new kind of defect.

Work through a release decision

Suppose a proposed version produces shorter explanations, but one item cites guidance for a different patient population. Hold that item and review other outputs that cite the same source. Fix the retrieval or drafting rule, then rerun both the affected items and the wider comparison set. Assign an owner to review similar reports after release.

For the broader approach to pre-deployment testing, source verification and monitoring, see the NIST Generative AI Profile. Use the MedQ-AI question review record to document decisions on individual drafts.
