Review numeric answer options before releasing a question

A number in an answer list can be shown as a proportion, a percentage, or a fraction. If those forms are mixed, the list may contain equivalent answers or reward students for noticing formatting. Use a separate pass to check the choices after the question is written.

Work the example without the choices

In a fictional assessment, 80 people take a diagnostic test. Fifty test positive and a reference standard confirms the condition in 30 of those 50. The question asks what percentage of the positive results came from people with the condition. The answer is 30 out of 50, or 60%.

A draft with choices of 0.60, 37.5%, 60%, and 5 in 8 contains two equivalent correct choices. It also changes how the values are expressed. Put all values in the requested unit and check for duplicates before setting the answer key.

Give wrong choices a reason to be there

Revised answer choices in increasing order
ChoiceWhat the calculation could represent
37.5%30 of all 80 tested. Uses all participants as the denominator.
40.0%20 of the 50 positive results. Counts the positive results from people without the condition.
60.0%30 of the 50 positive results. Uses the group named in the question.
62.5%50 of all 80 tested. Calculates the fraction of people whose test was positive.

These are possible explanations for an answer choice. Ask learners to explain their calculation before concluding which mistake they made.

Check the display the learner will see

Use the same precision unless the outcome calls for a different convention. Put rounding instructions in the question if they affect which answer is correct. Review the final display after editing or importing it. A system may round two originally distinct values to the same text.

See the NBME Item-Writing Guide. If the question is already in use, the distractor audit gives a way to check which choices learners select.
