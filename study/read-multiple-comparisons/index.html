Read multiple comparisons before choosing a study headline

A paper can test several outcomes, repeat them at different times, and examine several groups. Before using its most striking result to recommend a learning method, ask how many comparisons were considered and how the authors handled them.

A fictional journal-club example

Suppose researchers compare two teaching methods on five independent outcomes. For this simplified illustration, assume every null hypothesis is true and each test has a 5% false-positive probability. The probability of at least one false-positive result is 1 − 0.955, or about 22.6%. This calculation describes repeated testing under those assumptions; it is not the probability that a particular reported finding is false.

Actual outcomes may be correlated, so the independence calculation is not a universal estimate for a real paper. A result selected because it looks most impressive needs to be read in the context of the full analysis plan. The example is invented and does not report MedQ performance.

Make an analysis map

  • Outcome: Was the comparison about factual recall, a new-case assessment, or another measure?
  • Time: Was it the immediate quiz, a delayed test, or both?
  • Population: Was it everyone assigned to a method or a subgroup?
  • Plan: Was this analysis specified before the results were examined?
  • Multiplicity: Did the report describe an adjustment, a testing hierarchy, an exploratory interpretation, or no method?

One outcome tested at several time points can still create several comparisons. Calling an outcome “primary” does not, by itself, explain how multiple primary outcomes were handled.

Read the method before imposing a correction

CONSORT 2025’s outcome-comparison guidance asks reports to distinguish planned from post hoc analyses and describe how multiplicity was addressed, including when no method was used. It identifies multiple outcomes, repeated time points, and subgroup analyses as common settings where multiplicity matters.

For orientation, a simple Bonferroni approach to five tests at a family-wise level of 0.05 uses a threshold of 0.05 ÷ 5 = 0.01 for each test. This is an illustration, not an instruction to retroactively apply that threshold to every study. The appropriate set of tests and method depend on the research question and analysis plan. Do not invent an adjustment the authors did not report.

Write a bounded conclusion

Instead of “the new method worked,” a journal-club note might say: “One of five reported comparisons met the paper’s unadjusted 0.05 threshold. The report did not describe a multiplicity strategy; we would treat that result as exploratory and inspect the planned outcomes, effect estimates, and intervals before drawing a broader conclusion.” This is a fictional reporting example, not a judgment about a named study.

An exploratory result can be useful for designing a later study. Its value does not require presenting it as confirmation of a prespecified claim.
