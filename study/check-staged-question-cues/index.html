Check whether an earlier explanation gives away a later question

Staged questions reveal new information as a case unfolds. If the first answer explanation names the decision learners will face next, a correct second answer may reflect recall of that explanation. Choose the feedback timing based on what you want learners to practice and what you want the second answer to tell you.

Read the later stage with and without feedback

Consider a fictional study in which 40 participants test positive and 30 of them have the condition. Stage one asks for positive predictive value. A draft explanation calculates 75% and adds that sensitivity can be calculated only after counting all participants with the condition. Stage two then reveals that 60 participants had the condition and asks which metric uses that denominator.

The extra sentence supplies the answer to stage two. Ask a reviewer to try stage two using only the first vignette and the new information. Then show them the first explanation and ask which words would let them answer without working out the distinction.

Choose where feedback belongs

When learners are practicing with coaching
Keep the explanation between stages if you intend to model the reasoning before learners apply it. Ask them to explain which group goes in the denominator and why.
When you want the second answer to show independent reasoning
Hold the explanation until both responses are recorded. If the display gives immediate feedback, rewrite the second stage so it assesses a decision the feedback does not supply.

Audit each transition before publishing

  1. List the information the learner has seen when each stage opens. Include explanations, labels, and marked answers.
  2. Write the reasoning the next stage should elicit. Highlight prior wording that would replace that reasoning.
  3. Preview the case in each study mode. A review screen or retry mode may display a hint that was absent the first time.

NBME’s authoring documentation describes item sets that group questions around a shared vignette. This exercise applies that structure to a feedback-timing review. Use the question review record to note whether feedback belongs between stages or after the full case.
