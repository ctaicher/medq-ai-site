Review images in board-style questions

A practical checklist for verifying image rights, readability and the clue a learner needs to see.

MedQ-AI, founded by Christopher Taicher, MD

Start with the learning objective

Ask the reviewer to point to the visual finding that changes the reasoning. If the finding is the objective, make sure the stem leaves room for the learner to identify it. If the image is background, decide whether it adds context or draws attention away from the question.

Check the source and the rendered image

Record the source, license, credit, and any crop or annotation. Confirm the license covers the intended use before release. Use images cleared for educational publication and check for identifying marks in both the pixels and image metadata. Review the image at the same size learners will see on a phone. A crop that hides the relevant feature can change what the question tests.

Test the accessible version

For an image-based assessment, have an accessibility reviewer check whether the available text gives enough identification and whether an equivalent format is needed. Review an alternate format for the same learning objective and difficulty assumptions.

See the W3C images tutorial and the NBME Item-Writing Guide. Record the final decision in the question-review record.
